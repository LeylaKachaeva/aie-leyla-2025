## 2. Постановка задачи и контекст

1. **Предметная область и задача:** Банковское кредитование. Сервис оценивает вероятность дефолта по кредитной заявке. Пользователь — кредитный специалист банка.

2. **Формулировка задачи в терминах ML:** Бинарная классификация. Входные данные: возраст, доход, сумма кредита, срок, стаж, кредитная история, цель, сбережения. Целевая переменная: default (0/1). Требования: скорость <100мс, интерпретируемость.

3. **Целевые метрики качества:** Accuracy, Precision, Recall, F1-Score, ROC-AUC. ROC-AUC выбран как основная метрика для несбалансированных данных.

## 3. Данные

1. **Источник данных:** Синтетический датасет (создан в `src/data/load_data.py`)

2. **Структура данных:** 1000 записей. Признаки: числовые (6 шт.) и категориальные (2 шт.). Целевая переменная: default.

3. **Предобработка и EDA:** Стандартизация числовых признаков, One-Hot кодирование категориальных (drop='first'). EDA выполнен в `notebooks/01_eda_and_experiments.ipynb`: анализ распределений, корреляций, визуализация признаков по целевому классу. Классы сбалансированы (504/496).

## 4. Модели и подходы

1. **Базовые модели:** Logistic Regression (ROC-AUC 0.915)

2. **Улучшенные модели:** Random Forest (ROC-AUC 0.969), XGBoost (ROC-AUC 0.975)

3. **Нейросетевые модели:** Не применялись (табличные данные, ансамбли показали отличный результат)

## 5. Экспериментальный протокол и результаты

**Разделение данных:** Train 70% (700), Validation 15% (150), Test 15% (150)

**Сравнение моделей:**

| Модель | Accuracy | Precision | Recall | F1-Score | ROC-AUC |
|--------|----------|-----------|--------|----------|---------|
| Logistic Regression | 0.820 | 0.903 | 0.765 | 0.828 | 0.915 |
| Random Forest | 0.920 | 0.951 | 0.906 | 0.928 | 0.969 |
| XGBoost | 0.927 | 0.951 | 0.918 | 0.934 | 0.975 |

**Финальная модель:** XGBoost. Результаты на тесте: Accuracy 88.0%, ROC-AUC 0.961.

## 6. Архитектура решения и сервис

**Архитектура:** Python → FastAPI → joblib → модель XGBoost

**API endpoints:** `/` (информация), `/health` (проверка), `/predict` (предсказание)

**Технологический стек:** FastAPI, Uvicorn, scikit-learn, XGBoost, joblib, Docker, pandas, numpy

## 7. Наблюдаемость, конфигурация и безопасность

**Логи:** Каждый запрос логируется, ошибки с traceback, уровень INFO

**Health check:** `/health` возвращает статус сервиса и загрузки модели

**Конфигурации:** `configs/.env.example` с переменными MODEL_PATH, PREPROCESSOR_PATH, API_HOST, API_PORT, LOG_LEVEL, THRESHOLD

**Безопасность:** Секреты через .env, .env.example в репозитории, .env в .gitignore

## 8. Ограничения и дальнейшая работа

**Ограничения:** Синтетические данные, нет авторизации, нет персистентного хранения

**Развитие:** Реальные датасеты (Kaggle), JWT-аутентификация, облачное развёртывание (AWS/GCP), мониторинг (Prometheus + Grafana), веб-интерфейс (Streamlit)

## 9. Сценарий демонстрации на защите

1. Запуск сервиса: `python src/service/app.py`
2. Swagger UI: `http://localhost:8000/docs`
3. Запрос с низким риском (age=35, credit_history="good") → вероятность ~0.03%, risk low
4. Запрос с высоким риском (age=20, credit_history="poor") → вероятность ~99.98%, risk high
5. Docker: `docker build -t credit-risk-api .` и `docker run -p 8000:8000 credit-risk-api`
6. Ноутбук: `notebooks/01_eda_and_experiments.ipynb` с графиками и сравнением моделей
