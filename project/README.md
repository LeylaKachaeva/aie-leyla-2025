## 2. Распределение ролей и зоны ответственности

### Что делаем (суть проекта)
REST API сервис для оценки кредитного риска.  
На вход подаются характеристики клиента (возраст, доход, сумма кредита, срок, стаж, кредитная история, цель кредита, сбережения).  
На выходе сервис выдаёт:
- вероятность дефолта (0–1)
- категорию риска (low / medium / high)
- рекомендацию (0 — одобрить, 1 — отказать)

**Технологический стек:** Python 3.10, FastAPI, Uvicorn, scikit-learn, XGBoost, joblib, Docker, pandas, numpy, pytest.

## 3. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта
- `report.md` – отчёт по проекту
- `self-checklist.md` – чеклист самопроверки
- `notebooks/` – экспериментальные ноутбуки:
  - `01_eda_and_experiments.ipynb` – EDA и сравнение моделей
- `src/` – основной код проекта:
  - `src/data/load_data.py` – загрузка и предобработка данных
  - `src/models/train.py` – обучение и сравнение моделей
  - `src/service/app.py` – FastAPI сервис
- `artifacts/` – сохранённые модели:
  - `credit_risk_model.pkl` – модель XGBoost
  - `preprocessor.pkl` – пайплайн предобработки
- `configs/` – конфигурационные файлы:
  - `.env.example` – шаблон переменных окружения
- `tests/` – тесты:
  - `test_api.py` – тестирование API
- `Dockerfile` – контейнеризация сервиса

## 4. Требования и установка

### 4.1. Требования

- Python >= 3.10
- Docker (опционально)

### 4.2. Установка окружения

```bash
cd project
python -m venv .venv

# Windows:
.venv\Scripts\activate

# Linux/Mac:
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

## 5. Как запустить проект

### 5.1. Запуск обучения модели

```bash
cd project
python src/models/train.py
Модели сохраняются в artifacts/
```

### 5.2. Запуск сервиса (API)

```bash
cd project
python src/service/app.py
```

Сервис доступен по адресу: `http://localhost:8000`

**Эндпоинты:**
- `GET /` – информация о сервисе
- `GET /health` – проверка состояния
- `POST /predict` – предсказание вероятности дефолта

**Swagger UI:** `http://localhost:8000/docs`

### 5.3. Запуск с Docker

```bash
cd project
docker build -t credit-risk-api .
docker run -p 8000:8000 credit-risk-api
```
