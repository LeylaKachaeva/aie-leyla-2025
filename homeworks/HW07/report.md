## 2. Protocol

Опишите ваш "честный" unsupervised-протокол.

- Препроцессинг (единый для всех моделей внутри датасета):
  - Числовые признаки: `SimpleImputer(strategy="median")` → `StandardScaler()`.
  - Категориальные признаки (только dataset-04): `SimpleImputer(strategy="most_frequent")` → `OneHotEncoder(handle_unknown="ignore")`.
  - Препроцессинг реализован через `ColumnTransformer`, чтобы одинаково применять его ко всем сравниваемым алгоритмам на одном датасете.
- Поиск гиперпараметров:
  - KMeans: перебор `k` в диапазоне 2…20, фиксировали `random_state=42`, `n_init=20`.
  - DBSCAN: перебор `eps` по сетке (0.3, 0.5, 0.7, 1.0, 1.5) и `min_samples` (5, 10, 20).
  - Лучшее решение выбиралось по максимальному silhouette score (для DBSCAN — silhouette считался на non-noise точках).
- Метрики: считались 3 внутренние метрики качества без истинных меток:
  - `silhouette_score` (выше — лучше),
  - `davies_bouldin_score` (ниже — лучше),
  - `calinski_harabasz_score` (выше — лучше).
  Для DBSCAN дополнительно фиксировалась доля шума (`label = -1`), а метрики считались на non-noise точках (если после удаления шума оставалось ≥2 кластеров).
- Визуализация:
  - Для лучшего решения по датасету строился PCA(2D) scatter с раскраской по кластерам.
  - Для подбора параметров строились графики: silhouette vs k (KMeans) и silhouette vs eps (DBSCAN при фиксированном лучшем `min_samples`).
  - t-SNE не использовался.
