# HW10-11 – компьютерное зрение в PyTorch: CNN, transfer learning, detection/segmentation

## 1. Кратко: что сделано

- **Часть A (Классификация)**: Выбран датасет CIFAR10 (10 классов, 32x32). Проведены 4 эксперимента для сравнения подходов:
  - C1: простая CNN без аугментаций (baseline)
  - C2: та же CNN с аугментациями
  - C3: ResNet18 с замороженным backbone (head-only transfer learning)
  - C4: ResNet18 с частичным fine-tuning (layer4 + fc)

- **Часть B (Segmentation)**: Выбран датасет OxfordIIITPet с предобученной моделью DeepLabV3_ResNet50. Проведены 2 режима постобработки:
  - V1: без постобработки (базовые предсказания)
  - V2: улучшенная постобработка (удаление мелких компонент + морфологическая очистка)

## 2. Среда и воспроизводимость

- **Python**: 3.12
- **torch**: 2.10.0
- **torchvision**: 0.25.0
- **Устройство**: CPU
- **Seed**: 42 (зафиксирован для воспроизводимости)
- **Как запустить**: открыть `HW10-11.ipynb` и выполнить Run All (все ячейки последовательно)

## 3. Данные

### 3.1. Часть A: классификация

- **Датасет**: CIFAR10
- **Разделение**: train 40000, val 10000, test 10000 (80/20 от train)
- **Базовые transforms**: ToTensor(), Normalize(mean=[0.4914, 0.4822, 0.4465], std=[0.2470, 0.2435, 0.2616])
- **Augmentation transforms**: RandomHorizontalFlip, RandomRotation(15°), ColorJitter, RandomAffine
- **Комментарий**: CIFAR10 содержит 10 классов цветных изображений 32x32. Это стандартный датасет средней сложности, хороший выбор для сравнения различных подходов к классификации.

### 3.2. Часть B: structured vision

- **Датасет**: OxfordIIITPet
- **Трек**: segmentation
- **Что считается ground truth**: бинарная маска питомца (класс 2 в оригинальной разметке)
- **Какие предсказания использовались**: выход модели DeepLabV3_ResNet50, класс 2 интерпретируется как foreground (питомец)
- **Комментарий**: OxfordIIITPet хорошо подходит для задачи бинарной сегментации - содержит четкие маски питомцев на контрастном фоне. Размер валидационной выборки: 736 изображений.

## 4. Часть A: модели и обучение (C1-C4)

- **C1 (simple-cnn-base)**: 3 сверточных слоя (32→64→128) + 2 полносвязных слоя, ~620K параметров, без аугментаций
- **C2 (simple-cnn-aug)**: та же архитектура, но с аугментациями (flip, rotation, color jitter, affine)
- **C3 (resnet18-head-only)**: предобученный на ImageNet ResNet18, backbone заморожен, обучается только классификационная голова
- **C4 (resnet18-finetune)**: предобученный ResNet18, разморожены layer4 и fc для дообучения (partial fine-tune)

**Дополнительно:**
- **Loss**: CrossEntropyLoss
- **Optimizer**: Adam (lr=0.001 для C1-C3, lr=0.0001 для C4)
- **Batch size**: 64 для C1-C2, 32 для C3-C4 (из-за большего размера изображений после ресайза)
- **Epochs**: 5 (для всех экспериментов)
- **Критерий выбора лучшей модели**: максимальная accuracy на валидационной выборке

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)

### Выбран segmentation track

- **Модель**: DeepLabV3_ResNet50 (предобученная на COCO)
- **Что считается foreground**: класс 2 (питомец)
- **V1**: базовая постобработка (без дополнительной обработки)
- **V2**: альтернативная постобработка (удаление мелких компонент связности + морфологическая очистка)
- **Как считался mean IoU**: попиксельное сравнение бинарных масок (Intersection over Union)
- **Дополнительные метрики**: стандартное отклонение IoU, сравнение V1 vs V2

## 7. Анализ

**Классификация (часть A):**

Простая CNN показала достойный результат 74% на CIFAR10 всего за 5 эпох, что говорит о хорошо подобранной архитектуре. Аугментации дали небольшой прирост на валидации (+0.91%), но тестовая точность немного снизилась - это может указывать на то, что для полного эффекта от аугментаций требуется больше эпох обучения.

Transfer learning с ResNet18 дал значительный скачок качества. Особенно показателен результат C4 (partial fine-tune) - 91.30% всего за 5 эпох! Это демонстрирует мощь предобученных моделей: даже небольшое дообучение последних слоев позволяет быстро адаптировать признаки под специфику целевого датасета.

Интересно сравнить C3 и C4: head-only (80.63%) vs fine-tune (91.30%). Разница в +10.67% показывает, что для CIFAR10 важно не только использовать предобученные признаки, но и немного адаптировать их. Низкий learning rate (0.0001) позволил аккуратно дообучить слои без разрушения полезных признаков.

**Сегментация (часть B):**

DeepLabV3_ResNet50 хорошо справляется с сегментацией питомцев даже без дообучения (базовый IoU 0.65). Основные ошибки связаны с шумом на фоне и нечеткими границами.

Постобработка с удалением мелких компонент и морфологической очисткой дала улучшение на +3.13%. Это ожидаемый результат, так как предсказания часто содержат мелкие шумовые артефакты на фоне, которые эффективно удаляются при анализе связных компонент.

**Основные выводы:**
1. Transfer learning критически важен для достижения высокого качества на небольших датасетах
2. Partial fine-tuning дает значительный прирост по сравнению с head-only подходом
3. Даже простая постобработка может улучшить результаты сегментации
4. Аугментации требуют большего числа эпох для полного эффекта

## 8. Итоговый вывод

- **Базовый конфиг классификации**: best модель - ResNet18 с partial fine-tuning (C4), так как она дает наилучшее качество (91.30%) при умеренных вычислительных затратах.
- **Transfer learning**: главный вывод - предобученные модели значительно ускоряют обучение и повышают качество, причем даже небольшое дообучение (fine-tuning последних слоев) дает существенный прирост по сравнению с простым использованием как feature extractor.
- **Detection/Segmentation**: для структурных задач критически важна постобработка - она может значительно улучшить итоговое качество без изменения модели (в данном случае +3.13% к IoU).

Работа показала полный цикл решения задач компьютерного зрения: от простой CNN до transfer learning и сегментации с постобработкой.
